# Governed Test Contract

The npm source package contains executable tests outside the installed Skill
directory. They exercise the same importer stored under this Skill target.

Required suites:

- package identity and absence of npm lifecycle installers;
- deterministic import planning and neutral manifest defaults;
- Front Matter, figure ID, asset path, and original-source provenance;
- missing, remote, traversal, absolute, device, and symlink-escape resources;
- citation and local BibTeX boundaries;
- fresh install, unmanaged-target refusal, managed update, backup, and rollback;
- real offline `docforge inspect`, `validate`, and `build` on the comprehensive
  `file-backed fixture`.

Provider evaluation, external telemetry, and human blind review are
`missing evidence` until collected through the governed review flow.
