# docforge-project-skill

Create and package the `docforge-project` Agent Skill as the
`docforge-project-skill` npm package. The Skill converts an ordinary Markdown
document and its local resources into a new, valid DocForge Project Format V1
directory. It does not generate DOCX directly and is not thesis-specific.

Development is governed by the installed Yao Meta Skill engine. Yao remains
read-only; the locked Skill target is
`packages/docforge-project-skill/docforge-project/`.
